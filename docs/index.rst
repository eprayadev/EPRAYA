
EPRAYA documentation
====================

Epraya is a python package for EPR (Electron Paramagnetic Resonance) cw data analysis and simulation. It offers numpy-scipy and JAX based functions, that use only three containers: Ham, Exp and Vary. This ones can be modified by  users to insert hamiltonian parameters, experimental conditions and range for parameters' variation.
